# ben-pikus.github.io

Source for [ben-pikus.github.io](https://ben-pikus.github.io), the personal research website of Benjamin Pikus.

Built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) theme (MIT license).

To preview locally: `docker compose up`, then open http://localhost:4000.
